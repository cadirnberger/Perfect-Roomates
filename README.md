# RoomieMatch
Matching Algorithms
Here we will have two matching algorithms that are trying to assign students the best room based off their preferences. We are using Stable matching and Maximum Weight Bipartite Matching. Different input sizes will be used to determine which is better to solve this problem. 

Stable Matching 
To build and run this you will want to have and be able to run Python3.
1. Download project as ZIP.
2. Locate and open roomiematch.py
3. Choose input size of n= 5 through n=80
4. Run the file
In the terminal the output will show student to room matches and runtime.
